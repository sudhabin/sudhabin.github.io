Impedance Matching Guide & RF Engineering Notes RFSim99 Principles

⚡ L-Networks: 2-Element Minimum Loss

L-networks provide mathematically exact match using the minimum number of components (2 elements), offering the lowest insertion loss. The loaded Q is fixed by $\sqrt{R_{max}/R_{min} - 1}$. Low-pass versions are ideal for attenuating transmitter harmonics; high-pass versions block unwanted DC bias voltages.

📐 Pi (π) & T-Networks: 3-Element Bandwidth Control

Pi and T networks introduce an independent virtual intermediate resistance, allowing the designer to choose any loaded Q higher than $Q_{min}$. Pi-networks are preferred for tube/PA transistor outputs because their shunt capacitors absorb tube/transistor parasitic output capacitance.

🎯 Smith Chart Trajectory

A series element moves the impedance point along constant-resistance circles (clockwise for L, counter-clockwise for C). A shunt element moves the admittance point along constant-conductance circles (clockwise for C, counter-clockwise for L). Together they guide the load to the center $50\,\Omega$ point.
