What is fortune?About

🐧 The original command

fortune is a small Unix/Linux program that prints a random epigram, proverb, joke, or piece of “fortune cookie” wisdom. It has been part of the Unix culture for decades and is often used in login messages and shell startup files.

🌐 This web version

All fortunes are embedded in the page, so it works offline. The category selector narrows the pool; the refresh button picks a new quote without immediately repeating the previous one.

⌨️ Handy shortcuts

  • Space or N — another fortune
  • C — copy the current fortune
  • P — print the current fortune
