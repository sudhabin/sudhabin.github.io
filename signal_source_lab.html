What is a “signal source specification”?Section 1.5.2

A signal source is not just a voltage. It is a Thevenin equivalent: an open-circuit voltage VOC behind a source resistance RS. Almost every RF instrument uses RS = 50 Ω, and most receivers, spectrum analyzers, and coaxial cables are also designed for 50 Ω. The meter on a generator is calibrated as the power that would be delivered to a 50 Ω load — even when the real load is something else.

1 · The source setting

Pset in dBm is the power the generator would deliver to a matched 50 Ω load. It assumes RS = 50 Ω.

2 · The Thevenin model

VOC = 2 Vout,50 when RS = 50 Ω. That is a +6 dB step from the matched-load voltage to the open-circuit voltage.

3 · The real load

If RL ≠ 50 Ω, use voltage division: Vout = VOC RL/(RS+RL). The meter reading no longer equals the power in the load.

The 60 dB trap: dBµV vs dBmVUnit check
Read this first. EMC voltages are almost always quoted in dBµV (1 µV reference), not dBmV (1 mV reference). The two differ by exactly 60 dB: dBµV = dBmV + 60. A value like “84.5 dBµV” is 16.8 mV RMS — a perfectly ordinary signal level. If you read it as 84.5 dBmV, you would get 16.8 V, which is 1000× too large.
dBµV = 20 log₁₀( VRMS / 1 µV )
dBmV = 20 log₁₀( VRMS / 1 mV ) = dBµV − 60
dBm = 10 log₁₀( P / 1 mW )
At 50 Ω: dBµV = 107 + dBm
At 50 Ω: dBmV = 47 + dBm

Equations used in this labFormula sheet

Source & load

Vout = VOC · RL / (RS + RL)

When RL = RS = 50 Ω: Vout = VOC/2, i.e. VOC,dBµV = Vout,dBµV + 6 dB.

Pout = Vout,RMS² / RL

Matched cable

Vrec,dBµV = Vsource,dBµV + cable gaindB

A cable loss of 4.5 dB/100 ft over 200 ft is −9 dB of gain. Loss is subtracted; gain is negative dB.

Prec,dBm = Psource,dBm + cable gaindB

RMS, peak & power

Vpeak = √2 · VRMS
PdBm = 10 log₁₀(P / 1 mW)

Instrument voltages are RMS unless “peak” is stated explicitly. The ½ in P = Vpeak²/(2R) is already absorbed when you use RMS volts in P = VRMS²/R.

Mismatch

The meter assumes 50 Ω. With a different load, first find VOC, then use voltage division. The “mismatch loss” is

Lmismatch,dB = 10 log₁₀(Pset / Pload)

It is zero only when the load equals the source resistance (conjugate match for real impedances).

Worked example: −26 dBm into a 150 Ω loadPaul, Fig. 1.12

This is the exact numerical example from Section 1.5.2. Follow each step, then load it into the Workbench and change one number at a time.

  1. Convert dBm to power. P = 10−26/10 mW = 0.002512 mW = 2.512 µW.
  2. Find the voltage across a 50 Ω load. V50 = √(50 × 2.512×10−6) = 11.2 mV = 80.99 dBµV.
  3. Open-circuit voltage. VOC = 2 × 11.2 mV = 22.4 mV = 87 dBµV (the +6 dB step).
  4. Voltage division with 150 Ω. Vout = 150/(50+150) × 22.4 mV = 16.8 mV = 84.5 dBµV.
  5. Shortcut in dB. 20 log₁₀(150/200) = −2.5 dB, so 87 − 2.5 = 84.5 dBµV. The load power is (16.8 mV)²/150 = 1.88 µW = −27.3 dBm.
